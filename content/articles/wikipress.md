I almost have the blog integrated with the old [slipwave](http://comonad.com/reader/wiki;item=slipwave) wiki content. I kludged something together to display it in WordPress. While I may add a flashy dynamic in-page loading feature like [TiddlyWiki](http://www.tiddlywiki.com/), for right now its functional and backwards compatible with my old content and gracefully degrades in the absence of javascript.

By way of example, you might try to [view some Haskell source code](http://comonad.com/reader/source;item=Data;Haskell).

This also might provide better context when I start to talk about things like [continuations](http://comonad.com/reader/wiki?mode=category&item=continuations) because I can link right inline to more extended static content.

This also provides me with a more convenient venue for static content than WordPress' default page management system.
